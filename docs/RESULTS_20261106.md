# 实验 01：ADFWI PSV 与 HybridADFWI

2026-11-06，Sid。第一组受控测试已完成，三轮全部通过梯度检查。

## 配置

hpnewpc3-via-vps，RTX A5000 24 GiB，PyTorch 2.6.0+cu118。Marmousi-II 截取模型，78×200 网格，45 m，2500 步，dt=0.003 s，9 炮同时计算、100 个接收点，PSV / FD8 / split PML / 自由表面，Vp、Vs、rho 均求梯度。目标为固定观测 RMS 归一化的 `vz` 波形 L2。

两边都使用同一原生正演内核、同一个保留输入 dtype 的 padding 适配器，以及相同的 **50 段 checkpoint**。材料、波场、数据和梯度为 float64；FD 常数沿用上游 float32 生成的原值。该精度修正不编辑上游文件。

ADFWI 通过 checkpoint 重算并自动微分传播；HybridADFWI 对传播关闭 AD，只在数据端求 VJP，执行显式离散伴随，最后对静态材料映射做 VJP。两边的总时间均包含目标、重算、反传和敏感核计算，排除准备、预热和存储，不含优化器。

## 三次重复

| 指标 | ADFWI 原生 AD | HybridADFWI |
|---|---:|---:|
| 总耗时，均值 ± 样本标准差 | 144.62 ± 21.41 s | 54.01 ± 8.98 s |
| 各次总耗时 | 128.10 / 136.96 / 168.81 s | 63.60 / 45.80 / 52.63 s |
| 正演平均耗时 | 13.70 s | 12.87 s |
| 反向平均耗时，含重算及材料 VJP | 130.92 s | 41.13 s |
| CUDA allocated 峰值，各次相同 | 2.11267 GiB | 1.89532 GiB |
| CPU RSS 采样峰值，取三次最大值 | 1045.34 MiB | 839.32 MiB |

本配置下，两种方法平均总时间之比为 **2.678×**，HybridADFWI 耗时减少 **62.65%**；CUDA allocated 峰值减少 **10.29%**。这是对已有 checkpoint 优化的 AD 基线所做的额外节省。

CUDA allocated 为 PyTorch 活跃张量分配指标，不含全部驱动与进程上下文内存。CPU RSS 包含运行时及预热后保留的分配，不能解释为纯传播图大小；逐次 baseline、increment 和 reserved 指标均在原始 JSON 中。

## 梯度一致性

三轮的正演 `vz` 均逐位一致。每个原始敏感核均为有限 float64，形状 78×200，无平滑、裁剪、归一化或照明预条件。

| 参数 | 三次中的最大相对 L2 误差 |
|---|---:|
| Vp | 5.0106 × 10⁻¹² |
| Vs | 3.5764 × 10⁻¹² |
| rho | 3.5689 × 10⁻¹² |

全部小于事先设置的 1e-8 阈值，余弦接近 1。六份归档敏感核已在本地独立重算误差；原始文件清单、模型、上游 88 份源码及测量脚本哈希已核对。另有 17 项测试通过，包括五分量梯度、自由表面开关、不同 checkpoint、重复接收点和独立 Vs 中心差分。

## 运行条件与结果范围

实验只在 GPU 空闲时启动，单 CPU 线程、nice10，不更改其他 CPU 任务。七份逐 worker 资源审计共 254 次采样，未发现外部 GPU 计算进程；忽略的均为已验证的桌面进程。全部实验 GPU worker 已退出。

当时 32 个逻辑 CPU 上的 1 分钟 load 约为 38.98–41.66。**这是有 CPU 争用条件下的初次测量，不能视为独占机器的稳态加速比。** 三次重复已显示明显时间波动，论文性能结论仍需在更稳定的 CPU 条件下复测。

补充预热诊断在相同网格和 9 炮上，旧预热后连续运行三次 50 步 chunk。AD 耗时为 3.417 / 6.235 / 3.319 s；hybrid 为 0.922 / 1.325 / 1.743 s。没有观察到第一次更慢的现象；这不证明完全没有首次开销，也不用于修正或扣减正式数据。

本实验验证该离散实现的一阶模型梯度与资源开销；尚未测试优化迭代收敛、其他 ADFWI 物理模式、无 checkpoint 情况或跨求解器改造成本。
